# AOLAUF.HU APK v1 BETA

Android WebView app.

Compatibility:
- minSdk 21 = Android 5.0+
- targetSdk 28
- Java 8
- JavaScript enabled
- zoom disabled
- scrollbars disabled

AndroidIDE:
Open project -> Gradle Sync -> Build -> Assemble Debug.

APK:
app/build/outputs/apk/debug/app-debug.apk

The app loads https://aolauf.hu. Change MainActivity.java if another URL is needed.
